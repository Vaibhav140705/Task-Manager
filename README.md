# 📋 Task Manager

A simple and responsive **Task Management Web Application** built using **Flask**, **SQLite**, **HTML**, **CSS**, and **JavaScript**. It allows users to log in, create tasks, assign them, track progress, and manage task completion.

## 🚀 Features

- 🔐 Login Authentication (admin/admin)
- ➕ Add New Tasks
- 👤 Assign Tasks
- 📅 Set Deadlines
- 🎯 Priority Levels
- 📌 Task Status Tracking
- ✅ Mark Tasks as Completed
- 🗑 Delete Tasks
- 🔍 Search & Filter Tasks
- 📊 Dashboard Statistics
- 📤 Export Tasks to CSV
- 📱 Responsive UI

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask)
- **Database:** SQLite

## ▶️ Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Vaibhav140705/task-manager.git
   ```

2. Install dependencies
   ```bash
   pip install flask
   ```

3. Run the application
   ```bash
   python app.py
   ```

4. Open your browser
   ```
   http://127.0.0.1:5000
   ```
